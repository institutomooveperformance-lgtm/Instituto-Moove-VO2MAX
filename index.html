📖 Diretrizes Clínicas & Segurança Operacional

Instruções para condução segura do protocolo de esforço progressivo em esteira rolante.
Aquecimento Padronizado (Warm-up)
Duração obrigatória de 3 minutos com velocidade constante entre 5,0 e 6,0 km/h (caminhada rápida ou trote leve) e inclinação zero (0%). Este período permite adaptação neuromuscular à esteira, elevação gradual do débito cardíaco e redistribuição do fluxo sanguíneo sem indução de fadiga prematura.
Progressão do Protocolo de Esteira (Rampa Escalonada)
O teste inicia exatamente a 8,0 km/h com inclinação mantida em 0%. A cada estágio de 2 minutos (120 segundos), adiciona-se precisamente +0,5 km/h à esteira. Durante os últimos 15 a 20 segundos de cada estágio, o avaliador deve questionar a Percepção Subjetiva de Esforço (PSE Borg 0–10), registrar a FC pico do estágio e avaliar o Talk Test (capacidade de falar continuamente).
Critérios de Interrupção Imediata do Teste (ACSM Guidelines)
O teste deve ser interrompido imediatamente na ocorrência de qualquer um dos seguintes fatores:
1. Solicitação voluntária do avaliado por exaustão ou desconforto intolerável;
2. Sintomas neurológicos/vasculares: tontura, vertigem, palidez cutânea acentuada, descoordenação motora ou perda de equilíbrio;
3. Sintomas cardiovasculares: dor precordial, sensação de opressão torácica, dispneia desproporcional ao esforço;
4. Frequência cardíaca: elevação acima de 100% da FC máxima prevista para a idade acompanhada de fadiga extrema ou ausência de incremento cronotrópico com aumento de carga (platô anormal).
Volta à Calma & Conduta Pós-Esforço (Cool-down)
NUNCA pare a esteira abruptamente após o término do esforço máximo, sob risco iminente de hipotensão pós-exercício, estase venosa nos membros inferiores e síncope vasovagal. Reduza a esteira imediatamente para 4,5 km/h a 0% de inclinação e mantenha o avaliado caminhando por pelo menos 2 minutos, monitorando os valores de FC aos 60s e aos 120s para o cálculo da recuperação autonômica.

📘 Como configurar o Google Apps Script (passo a passo)
  1. Crie uma planilha no Google Sheets (ex.: "Instituto Moove — Dados").
  2. No menu superior da planilha, clique em Extensões → Apps Script.
  3. Substitua todo o código do arquivo Código.gs pelo script fornecido abaixo.
  4. No canto superior direito, clique em Implantar → Nova implantação. Selecione o tipo de engrenagem Aplicativo da Web.
  5. Defina Executar como: "Eu" e Quem tem acesso: "Qualquer pessoa" (Anyone).
  6. Clique em Implantar, autorize as permissões da sua conta Google, copie a URL do aplicativo da web (termina em /exec) e cole no campo acima.
Código Google Apps Script pronto para copiar: 
function doGet(e) {
  var prop = PropertiesService.getScriptProperties();
  var raw = prop.getProperty("MOOVE_DATA");
  var payload = raw ? JSON.parse(raw) : {
    alunos: [],
    professores: [],
    avaliacoes: [],
    config: {},
    excluidos: { alunos: [], professores: [], avaliacoes: [] }
  };
  return ContentService.createTextOutput(JSON.stringify(payload))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var body = e.postData.contents;
    var parsed = JSON.parse(body);
    PropertiesService.getScriptProperties().setProperty("MOOVE_DATA", JSON.stringify(parsed));
    return ContentService.createTextOutput(JSON.stringify({ status: "ok", timestamp: new Date().toISOString() }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
